## What does this multiplayer mod do?

lets you play black souls with up to 3 friends!! (4 people total)

the host plays the game like normal, everyone else follows the host around as party members

- everyone sees the same stuff, maps, dialogue, CGs, fog, music, all of it
- in fights everyone picks their own moves
- everyone uses their OWN character, gear and items
- nobody's save gets messed with, guests get their own progress saved
- theres a chat!! press T to talk, Enter to send
- there's discord rich presence.
- if a friend dies they stay dead until someone revives them (campfire, skill or item)
- you can heal each other with items

## How to connect to friends

<img width="792" height="264" alt="whydidyoumakemesearchyou" src="https://github.com/user-attachments/assets/3a8afa46-8ac8-49ae-8373-433e838a2f0c" />

1. download BS Multiplayer Patcher.exe from releases (you DONT need python)
2. open it, check the game folder is right
3. everyone has to have the same version of the exe!!

HOST:
- pick "host the party" and press start
- copy "your code" and send it to your friends

FRIENDS:
- pick "join a party"
- paste the host's code into "host address" and press start
- wait a few seconds, you should pop into their game!


your code gets sent to the host by itself now. if it doesnt work after a minute, copy YOUR code and send it to the host, then the host pastes it into "guest code" and presses add

OR just press Join on the host's discord invite, the patcher opens by itself, pick your look and press start

do it kinda quick, it only keeps trying for 15 min. if it still wont connect try tailscale

if you want steam achievements, tick "Launch with steam" before pressing start

if you open the game normally (without the patcher) its just normal black souls 2, co-op only turns on through the patcher
